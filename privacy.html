Kebijakan Privasi

Berlaku sejak 16 Oktober 2026

Data yang diakses

Dengan izin pengguna, myBlu mengakses Gmail pengguna dengan cakupan baca saja (https://www.googleapis.com/auth/gmail.readonly). Aplikasi hanya membaca email dari receipts@blubybcadigital.id, yaitu notifikasi transaksi blu by BCA, untuk mengambil nominal, tanggal, jenis transaksi, nama merchant atau lawan transaksi, dan nomor referensi.

Cara data digunakan

Data tersebut hanya dipakai untuk menampilkan ringkasan keuangan kepada pengguna itu sendiri di dalam aplikasi. myBlu tidak membaca, mengubah, menghapus, atau mengirim email lain.

Penyimpanan

Data transaksi disimpan di basis data lokal pada komputer pengguna. Token login Google disimpan di Keychain macOS. myBlu tidak memiliki server, tidak mengirim data ke pihak mana pun, tidak memakai data untuk iklan, dan tidak menjual atau membagikan data.

Google API Services User Data Policy

Penggunaan dan pemindahan informasi yang diterima dari Google API oleh myBlu mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Menghapus data dan mencabut akses

  • Di aplikasi: Pengaturan → Hapus semua transaksi, dan Keluar dari Google untuk menghapus token.
  • Kapan saja melalui myaccount.google.com/permissions.

English summary

myBlu requests read-only Gmail access solely to read blu by BCA transaction emails from receipts@blubybcadigital.id and display a financial summary to the same user. All data stays on the user's computer; nothing is sent to any server or third party. myBlu's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Kontak

Pertanyaan dapat dikirim ke email dukungan yang tercantum di layar izin Google saat login.
